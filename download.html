Download & install

Get the installer for your machine. biofmt runs entirely locally — sample sheets, FASTQ, and GTF/GFF3 files never leave the computer you install it on. There is no public source repository.

Download for Windows macOS — coming soon

Verify the download (SHA-256)

Before you run the installer, check that the file matches this hash. That confirms it is the build we published for v0.1.0, not a swapped copy.

6e867b18c43f663b6dfd17841dddc8e3d63f3296171fa28c99458e7b2106ce9a

On Windows, in PowerShell or Command Prompt:

certutil -hashfile biofmt-windows-setup.exe SHA256

The printed hash should match the value above (case does not matter). File size is about 66 MB.

Windows

  1. Download biofmt-windows-setup.exe from the button above. Only use the copy from this site or the matching GitHub Release.

  2. Optionally verify the SHA-256 hash (section above).

  3. Run the installer. If SmartScreen warns that the app is unrecognized, that is expected until we ship a signed build — choose More info, then Run anyway, and only if you came from this page and the hash matches.

  4. Launch biofmt from the Start menu. The installer also places Biofmt.exe in your install folder.

macOS

The macOS installer is not ready yet. Windows is the first supported download.

After install

The packaged app includes the local GUI. For CLI use from a terminal after install, run the installed Biofmt.exe with the same subcommands documented in the docs (profiles: generic, cellranger, nfcore-rnaseq).

Requirements

  • Windows 10 or newer (64-bit)
  • No separate Python or git install required

Files never leave your machine — local only, no upload, no telemetry. Do not run an installer emailed to you or linked from a random post — only the button on this page (or the matching Release).

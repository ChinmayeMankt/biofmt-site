Catch the sample-sheet, FASTQ, GTF, and Excel-gene errors that kill your pipeline run — before you queue the job.

biofmt is a local pre-flight validator for genomics pipeline inputs. It checks the files on your computer and tells you what's wrong, in plain terms, before Cell Ranger, nf-core, or a GATK-style workflow does it for you at hour six.

Install biofmt Read the docs

The problem

A sample sheet has an unnamed Excel column. A gene list has "SEPT2" silently turned into a date. A FASTQ pair is missing a mate. A GTF is missing transcript rows that Cell Ranger expects. None of this shows up until the pipeline is already running — or has already failed, an hour or a day in.

biofmt runs before that. It reads your inputs, checks them against known failure patterns, and reports specific, addressable findings — not a generic "invalid file" message.

What it checks

Sample sheets

Missing required columns, duplicate or illegal sample IDs, reserved names, missing FASTQ paths, index length and Hamming distance, unnamed Excel columns, constant design columns.

FASTQ

Truncated records, sequence/quality length mismatch, @ vs + id mismatch, empty files, interleaved reads, mixed Phred encoding, Cell Ranger filename pattern checks, suffix-vs-content mismatch.

GTF / GFF3

Missing transcript rows, missing gene_id/transcript_id, dangling Parent references, invalid coordinates, duplicate IDs, strand conflicts, gene_name collisions.

Cross-file checks

Sample IDs vs FASTQ-derived names, chr-prefix mismatches, mixed contig sets, suspect reference builds.

Gene lists

Excel date mutilation (2-Sep → SEPTIN2), withdrawn symbols, ambiguous aliases, mixed Ensembl IDs / symbols / dates in one column.

biofmt does not align reads, run Cell Ranger, run nf-core, or call variants. It checks inputs before you hand them to those tools.

Install

For analysts running the CLI:

python -m pip install -e ".[gui]"
python -m biofmt validate FOLDER --sheet SHEET.csv --profile cellranger

For lab staff who'd rather use a window, see the Windows install guide.

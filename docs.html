Command reference

biofmt is a CLI (with an optional local GUI) that checks pipeline inputs. It does not modify your source files unless you explicitly run fix with --write, and even then it writes to a separate output directory.

biofmt inspect

Look at a file or folder and report what biofmt thinks it is, without running full validation.

python -m biofmt inspect PATH

biofmt validate

Run the full set of checks against a folder of pipeline inputs, optionally cross-checked against a sample sheet.

python -m biofmt validate PATH [--sheet PATH] [--profile generic|cellranger|nfcore-rnaseq]
  • --sheet PATH â€” a sample sheet (CSV or Excel-style) to cross-check sample IDs, paths, and index barcodes against.
  • --profile â€” which pipeline's expectations to check against. Defaults to generic if omitted.

biofmt genes

Check a gene list file for Excel mutilation, withdrawn symbols, ambiguous aliases, and mixed identifier types.

python -m biofmt genes FILE

biofmt fix

Write corrected copies of inputs where a fix is unambiguous. Original files are never overwritten.

python -m biofmt fix ... --write DIR

biofmt gui

Open a local Streamlit window for running the same checks without a terminal. Files stay on the machine running the GUI.

python -m biofmt gui

Finding IDs

Every issue biofmt reports has a stable finding ID, grouped by the kind of file it applies to. A few examples from each group:

Sample sheet (sheet.*)

sheet.required_columnsA required column is missing from the sheet.
sheet.duplicate_sample_idThe same sample ID appears more than once.
sheet.illegal_sample_idA sample ID contains characters that will break downstream tools.
sheet.reserved_nameA sample ID collides with a reserved name.
sheet.path_missingA referenced FASTQ path doesn't exist.
sheet.index_lengthAn index/barcode is an unexpected length.
sheet.index_hammingTwo indexes are too close in Hamming distance to demultiplex reliably.
sheet.unnamed_columnsAn unnamed column, usually from an Excel export artifact.
sheet.constant_design_columnA design column has the same value in every row.
sheet.excel_csvThe file looks like an Excel export with formatting quirks intact.

FASTQ (fastq.*, detect.*)

fastq.id_mismatchThe @ header and + line disagree.
fastq.length_mismatchSequence and quality string lengths don't match.
fastq.truncatedA record ends mid-way through.
fastq.emptyThe file has no records.
fastq.phred_mixedQuality scores suggest more than one Phred encoding in the same file.
fastq.pair_count_mismatchR1 and R2 have different read counts.
fastq.interleavedThe file looks interleaved rather than single-end.
fastq.cellranger_nameFilename doesn't match the expected Cell Ranger naming pattern.
detect.suffix_content_mismatchFile extension doesn't match its actual content.

GTF / GFF3 (gtf.*, gff.*)

gtf.missing_transcriptGene rows exist without corresponding transcript rows (required by Cell Ranger).
gtf.missing_attributesA row is missing gene_id or transcript_id.
gtf.incompatible_profileThe file's structure doesn't match the selected pipeline profile.
gff.dangling_parentA Parent attribute references an ID that doesn't exist.
gff.coord_invalidStart/end coordinates are malformed or out of order.
gff.duplicate_idThe same feature ID appears more than once.
gff.strand_conflictA feature and its parent disagree on strand.
gff.gene_name_collisionTwo different gene IDs share the same gene name.
gff.source_dialectThe file's source field suggests a dialect that may affect parsing.

Cross-file (sample_id.*, contig.*, ref_build.*, missing.*)

sample_id.mismatchSample sheet IDs don't line up with FASTQ-derived names.
contig.prefix_mismatchSome files use a chr prefix and others don't.
contig.set_mismatchFiles reference different contig sets.
ref_build.suspectContigs suggest a reference build different from the one specified.
missing.filesA file referenced elsewhere could not be found.

Gene lists (gene.*)

gene.excelA gene symbol was silently converted to a date by Excel (e.g. 2-Sep for SEPTIN2).
gene.ambiguousA symbol maps to more than one gene alias.
gene.withdrawnA symbol has been withdrawn or superseded.
gene.id_mixedThe column mixes Ensembl IDs, symbols, and/or dates.

This is not the full list of finding IDs â€” it's a representative sample from each category. Run biofmt validate or biofmt genes against your own files to see everything that applies.
